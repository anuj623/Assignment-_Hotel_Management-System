# Hotel Booking Management System

## Project Configuration
- **Backend:** Node.js, Express, MongoDB Atlas
- **Frontend:** Component-driven React engine.

## Setup & Running Guide
1. Run backend server: `cd backend && npm install && npm start`
2. Populate dynamic seed data: `cd backend && npm run seed`
3. Launch React application dashboard: `cd frontend && npm install && npm run dev`

## Features

- User Management
- Hotel Management
- Booking Management
- Pagination
- Filtering
- Sorting
- Excel Export
- Reusable Components
